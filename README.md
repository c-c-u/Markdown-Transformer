# 公式编辑器 · Markdown 实时输出

一个基于 Python + Tkinter 的可视化公式编辑器。公式直接显示在画布中：点击黄色方框即可定位输入，也可以用键盘方向键在结构内部位置和结构两侧的隐藏空位之间切换；用工具栏插入求和、积分、微分、分式、乘方、开方、矩阵和向量等结构；点乘、叉乘等单符号运算符也可以直接从运算符面板插入。

**Markdown 源码和渲染预览都会随公式实时更新**，填写完整后可以直接复制。

## 功能一览

- **可视化公式画布**：不显示 LaTeX 源代码，画布本身就是编辑器与实时预览。
- **点击方框输入**：模板中预留的黄色方框可以直接点击；结构两侧的隐藏输入位置不画方框，用方向键进入后也可直接输入。
- **自动适配的画布**：
  - 简单公式时画布保持较小高度，把空间留给输出区；
  - 公式变高时画布自动长高，直到窗口允许的上限；
  - 超过上限时自动缩小字号以适配。
- **常用结构模板**：
  - `∑ 求和`
  - `∫ 积分`
  - `d/dx 微分`
  - `a/b 分式`
  - `xⁿ 乘方`
  - `√ 开方`（平方根 / n 次根）
  - `矩阵`（2×2、3×3、2×3、3×2）
  - `向量`（2×1、3×1 列向量；1×2、1×3 行向量）
- **单符号运算符面板**：
  - 直接按钮：`·`、`×`、`±`、`∓`、`≤`、`≥`、`≠`、`∞`、`∂`、`∇`
  - 「更多符号」菜单：`÷`、`≈`、`≡`、`∝`、`∈`、`∉`、`⊂`、`⊆`、`⊃`、`⊇`、`∪`、`∩`、`∖`、`∅`、`∧`、`∨`、`¬`、`∀`、`∃`、`→`、`⇒`、`⇔`、`∘`、`⊥`、`∥`、`≅`、`≪`、`≫`
- **模板嵌套**：先选中某个空方框，再点击模板按钮，可以把新模板插入到该位置。
- **结构两侧的隐藏输入位置**：每个结构左右自动存在一个可编辑位置，但不绘制方框；获得焦点时只显示光标。用 `←` / `→` 可从结构内部位置切到相邻空位，直接输入运算符、系数或另一个结构。
- **键盘导航**：`Tab` / `Shift+Tab` 在方框和已填写文本之间切换；`←` / `→` 在文本内移动光标，到达文本开头/结尾后自动切换到相邻输入位置；`Backspace` / `Delete` 删除字符。
- **实时 Markdown 输出**：
  - 左侧 Markdown 源码随公式即时更新；
  - 右侧公式渲染预览同步更新；
  - 只有所有必填方框都填写完整时，源码才生成、复制按钮才可用；结构两侧的隐藏位置可以留空。
- **编辑辅助**：撤销 / 重做 / 清空、Windows 剪贴板复制。

## 运行环境

本项目使用 conda 的 **transcript** 环境。当前环境已安装：

| 组件 | 版本/说明 |
| --- | --- |
| Python | 3.12.11 |
| Tkinter / Tk | Python 自带，Tk 8.6 |
| matplotlib-base | 3.10.9（使用 Agg 后端渲染输出预览） |
| Pillow | 11.1.0（用于预览图缩放与窗口图标） |

如需在新机器上重建环境：

```powershell
conda create -n transcript python=3.12.11 tk matplotlib-base=3.10.9 pillow=11.1.0 -y
conda activate transcript
```

> 这里安装 `matplotlib-base` 而不是 `matplotlib` 的完整 meta 包，是因为主要使用 Agg 后端，可以避免额外安装 PyQt 等 GUI 依赖。

## 启动程序

```powershell
conda activate transcript
python formula_editor.py
```

如果 conda 激活不方便，可以直接使用环境中的 Python：

```powershell
C:\Conda\envs\transcript\python.exe formula_editor.py
```

## 快速上手：求和公式

以输入下面的求和公式为例：

```
∑_{i=1}^{n} i²
```

1. 启动程序后，画布中央只有一个输入光标（初始根位置不显示方框），可以直接输入或插入模板。
2. 点击「∑ 求和」按钮，画布中会插入：
   - ∑ 符号；
   - 上方方框（求和上限）；
   - 下方方框（求和下限）；
   - 右侧方框（求和项）。
3. 用鼠标点击「求和下限」方框，输入 `i=1`。
4. 点击「求和上限」方框（或按 `Tab`），输入 `n`。
5. 点击右侧的「求和项」方框（或再按 `Tab`），输入 `i^2`。
6. Markdown 输出区会立即出现源码：

   ```markdown
   $$
   \sum_{i=1}^{n} i^2
   $$
   ```

   右侧同时显示渲染后的公式预览。

7. 点击底部「复制 Markdown」即可粘贴到 Typora、Obsidian、GitHub、VS Code 等支持 `$$` 数学公式的 Markdown 编辑器。

> 画布中的已填写文本仍然是普通字符，例如输入 `i^2` 时画布显示 `i^2`，右侧渲染预览会按 LaTeX 显示为 `i²`。最终排版效果以右侧预览为准。

## 新增运算符与大型结构

### 单符号运算符

运算符面板在第二行。直接点击即可插入到当前选中的方框或文本光标处。

| 按钮 | 含义 | 导出 LaTeX |
| --- | --- | --- |
| `·` | 点乘 / 内积 | `\cdot` |
| `×` | 叉乘 / 乘号 | `\times` |
| `±` | 正负 | `\pm` |
| `∓` | 负正 | `\mp` |
| `≤` `≥` `≠` | 关系符号 | `\leq` `\geq` `\neq` |
| `∞` | 无穷 | `\infty` |
| `∂` | 偏导符号 | `\partial` |
| `∇` | 梯度算子 | `\nabla` |

「更多符号」菜单还提供：

- 算术：`÷` `≈` `≡` `∝`
- 集合：`∈` `∉` `⊂` `⊆` `⊃` `⊇` `∪` `∩` `∖` `∅`
- 逻辑：`∀` `∃` `∧` `∨` `¬`
- 箭头：`→` `⇒` `⇔`
- 其他：`∘` `⊥` `∥` `≅` `≪` `≫`

单符号作为普通文本插入，仍然可以点击后删除、移动光标或替换。

### 结构模板

| 按钮 | 插入结构 | 可编辑位置 |
| --- | --- | --- |
| ∑ 求和 | `\sum_{□}^{□} □` | 下限、上限、求和项 |
| ∫ 积分 | `\int_{□}^{□} □\,\mathrm{d}□` | 下限、上限、被积函数、积分变量 |
| d/dx 微分 | `\frac{\mathrm{d}□}{\mathrm{d}□}` | 分子变量、分母变量 |
| a/b 分式 | `\frac{□}{□}` | 分子、分母 |
| xⁿ 乘方 | `{□}^{□}` | 底数、指数 |
| √ 开方 | `\sqrt{□}` | 被开方数 |
| n 次根 | `\sqrt[□]{□}` | 被开方数、根指数 |
| 矩阵 | `\begin{pmatrix} … \end{pmatrix}` | 各单元格 |
| 向量 | `\begin{pmatrix} … \end{pmatrix}` | 各分量 |

「√ 开方」是下拉菜单，可选择平方根或 n 次根。

「矩阵」菜单提供 2×2、3×3、2×3、3×2 四种尺寸；「向量」菜单提供 2×1、3×1 列向量和 1×2、1×3 行向量。

### 示例：乘方与开方

1. 点击「xⁿ 乘方」，出现底数和指数两个方框；
2. 在底数方框输入 `x`，按 `Tab` 在指数方框输入 `2`；
3. 得到源码：

   ```markdown
   $$
   {x}^{2}
   $$
   ```

4. 点击「√ 开方」→「n 次根」，填写被开方数和根指数，例如 `x` 和 `3`，得到：

   ```markdown
   $$
   \sqrt[3]{x}
   $$
   ```

### 示例：矩阵与向量

1. 点击「矩阵」→「2 × 2 矩阵」，画布中出现 2×2 个方框；
2. 用鼠标点击单元格，或按 `Tab` 依次填写；
3. 例如填写 `a`、`b`、`c`、`d`，源码为：

   ```markdown
   $$
   \begin{pmatrix} a & b \\ c & d \end{pmatrix}
   $$
   ```

4. 点击「向量」→「3 × 1 列向量」，填写三个分量即可生成列向量。

矩阵单元格本身也是普通方框，可以在单元格里继续插入乘方、分式、根号等结构。

> **矩阵预览说明**：matplotlib mathtext 不支持 `pmatrix` 环境，因此含矩阵/向量的公式，右侧实时预览会自动改用与画布相同的自绘布局；复制出的 Markdown 仍然是标准 `pmatrix`，可被 GitHub、Typora、Obsidian、VS Code 等支持 LaTeX 的 Markdown 渲染器正确显示。

### 在结构两侧输入内容

每个结构（求和、积分、微分/分式、乘方、开方、矩阵等）的左右两侧会自动存在一个输入位置：

- 该位置**不绘制黄色方框**；获得焦点时只显示光标；
- 如果该侧已经有空方框或已填写文本，则直接复用已有位置，不重复生成；
- 使用 `←` / `→` 可以从结构内部位置切换到相邻的隐藏空位：
  - 在结构第一个内部位置按 `←` 进入左侧空位；
  - 在结构最后一个内部位置按 `→` 进入右侧空位；
  - 在空位中继续按反方向键可回到结构内部。

在右侧空位直接输入 `+`，再点击「∫ 积分」，即可得到：

```markdown
$$
\sum_{i=1}^{n} i^2+\int_{0}^{\infty} e^{-x^2}\,\mathrm{d}x
$$
```

结构内部用于填写上下限、分子分母、矩阵单元格等的空位仍然显示黄色方框；结构两侧的隐藏空位只是可选的扩展位置，保持空白也不会阻止复制。

## 画布大小与自动扩展

- 空白或简单公式时，画布保持较小高度，下方空间主要留给 Markdown 源码和预览。
- 插入求和、积分、矩阵或公式内容变高时，画布会自动变大。
- 画布高度上限随窗口高度调整；窗口越大，可扩展的高度越多。
- 超过上限时会自动降低字号适配。
- 删除内容后画布会自动缩回较小高度。

## 实时输出与预览

Markdown 源码在公式填写完整后立即生成，内容为块级数学公式：

```markdown
$$
\sum_{i=1}^{n} i^2
$$
```

其他示例：

```markdown
$$
\int_{0}^{\infty} e^{-x^2}\,\mathrm{d}x
$$
```

```markdown
$$
\frac{\mathrm{d}y}{\mathrm{d}x}
$$
```

```markdown
$$
{a}^{2} \cdot {b}^{2}
$$
```

```markdown
$$
\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}
$$
```

```markdown
$$
\sqrt[3]{x}
$$
```

「Markdown 输出」区域分为两栏：

- **左侧 Markdown 源码**：随公式实时更新，可直接选择、复制；复制按钮在底部操作栏。
- **右侧实时预览**：
  - 普通公式使用 matplotlib mathtext 渲染；
  - 含矩阵/向量时自动切换为画布自绘预览；
  - 还有未填写的必填方框时显示剩余数量。

如果公式包含 mathtext 不支持的其他语法，右侧会显示渲染错误；左侧源码和复制按钮仍然可用。

## 项目结构

```
project/
├── formula_editor.py   # 主程序（公式树、画布布局、编辑交互、实时输出）
├── README.md           # 本说明文件
└── .git/               # 仓库元数据（如存在）
```

`formula_editor.py` 内部大致分为：

1. **公式树模型**：`Slot`、`TextRun`、`Placeholder`、`SumNode`、`IntegralNode`、`FractionNode`、`SuperscriptNode`、`RootNode`、`MatrixNode`。
2. **画布布局引擎**：计算每段文本、方框、分式、根式、乘方、矩阵的位置与尺寸，生成点击热区和大型结构包围盒；同时根据公式高度决定画布高度。
3. **`FormulaEditorApp`**：
   - 构建 Tkinter/ttk 界面与交互式 Canvas；
   - 处理点击、键盘输入、Tab 跳转、撤销/重做；
   - 自动为结构左右生成不绘制方框的隐藏输入位置；
   - 每次公式变化时立即同步 Markdown 源码；
   - 用 matplotlib mathtext 渲染普通公式预览，矩阵公式使用画布自绘预览；
   - 剪贴板复制。
4. **`main()`**：DPI 感知、窗口入口和 `--smoke-test` 冒烟测试。

## 实现说明与已知限制

- 画布是自定义公式编辑器，不是从 LaTeX 源码解析生成的只读预览；公式结构真正可点击、可编辑。
- 画布中的字体使用 Cambria（正文）和 Segoe UI Symbol（运算符符号）。方框内输入的是普通字符，画布不做完整的 LaTeX 排版；例如 `^2` 会保留为 `^2` 字符，最终排版请以右侧实时预览为准。
- 输出预览使用 **matplotlib mathtext**，支持常用数学结构，但不是完整 LaTeX 引擎。`pmatrix` 矩阵环境不被 mathtext 支持，因此矩阵公式使用自绘画布预览；`\begin{aligned}`、宏包、中文文本等其他不支持语法会在右侧显示错误，但源码仍可复制。
- 画布会随公式自动长高，但高度上限受窗口大小限制；超过上限后会自动缩小字号，而不是继续扩大窗口。
- 非结构型空位（结构左右两侧、初始空白根位置）不再绘制方框，只在获得焦点时显示光标；结构内部的上下限、分子分母、矩阵单元格等必填位置仍显示黄色方框。
- 结构左右两侧的隐藏位置会自动生成；若该侧已有可编辑文本或方框则直接复用，不重复生成。用 `←` / `→` 可在结构内部位置和相邻隐藏位置之间切换。
- 矩阵和向量插入后尺寸固定，可先在菜单中选好尺寸；单元格内可以继续嵌套结构。
- Markdown 输出为 `$$ ... $$` 块级公式；如果目标平台只支持行内 `$...$`，可以后续增加输出格式切换。

4. 在布局引擎中实现该结构的排版和点击热区；
5. 在 `serialize_item()` 中补充 LaTeX 序列化。
