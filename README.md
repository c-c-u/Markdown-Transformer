# 公式编辑器 · Markdown 实时输出

一个基于 Python + Tkinter 的可视化公式编辑器。公式直接显示在画布中：点击黄色方框即可定位输入，点击一段文本的最左侧或最右侧可以在这段文本旁添加新的输入位置，也可以用键盘方向键在结构内部位置和结构两侧的隐藏空位之间切换；用工具栏插入求和、积分、微分、分式、角标、开方、矩阵和向量等结构；点乘、叉乘等单符号运算符也可以直接从运算符面板插入。

**Markdown 源码和渲染预览都会随公式实时更新**，填写完整后可以直接复制。

## 公式组成规范

程序中的一切操作都按同一套术语来描述：**结构**、**算符**、**键入**。方框是否显示、删除时是否会连带结构，都由这几条规则决定；先理解它们，再看下面的功能与示例会更容易。

### 结构

**结构**是一个完整的式子的称呼，它是公式中「一段有头有尾、可以整体点击和填写的内容」。

- **基本结构**是最简单的结构：内部不含有标点符号（算符），是一段连续的字符，例如 `x`、`2`、`ab`、`x²`、`i`。
- **复合结构**由**更小一级的结构**和**算符**递归地拼成。例如：
  - `a/b` 是分式结构，由分子结构 `a`、分数线算符和分母结构 `b` 组成；
  - `∑` 是求和结构，由下限、上限、求和项三个结构，以及 `∑` 算符组成；
  - `\sqrt{x+1}` 是开方结构，里面装的是 `x+1` 这个由 `+` 算符拼成的复合结构。
- 递归是任意的：任何结构的位置里都可以放另一个结构，例如矩阵单元格里可以放分式，分式分子里又可以放根号。
- 整个公式最外层也算一个结构（画布中空白时光标所在的那一行）。

### 算符

**算符**是把结构分隔开或组合起来所用的东西。按「是否带有结构位置」分成两类：

| 类别 | 说明 | 例子 |
| --- | --- | --- |
| 单行算符（无结构位置） | 只在同一行内、仅对**前后两个结构**进行运算，不需要额外的位置 | `+`、`-`、`×`、`·`、`÷`、`±`、`=`、`≤`、`→`、`∈` 等 |
| 结构算符（有一个或多个结构位置） | 需要把更小的结构填进它规定的位置里，位置就是画布中的方框 | 根号占 1 个位置（被开方数）；分数线占 2 个位置（分子、分母）；求和、积分占上下限与求和项/被积函数等多个位置；矩阵占若干个单元格位置 |

- 单行算符**不会**用方框标出，直接作为字符写在一行里。
- 结构算符**除方框以外没有别的写法**：它的每一个位置都显示为方框（矩阵单元格、上下限、分子分母等），必须填写。
- 方框只表示「结构算符的位置」。结构左右两侧的隐藏输入位置、公式开头的空白位置都不是结构算符的位置，因此**不画方框**，只在获得焦点时显示光标。
- 逗号、分号、绝对值竖线、矩阵括号、`\mathrm{d}` 之类的写法在 LaTeX 里承担算符角色，但在本程序中它们不作为独立算符：或由结构本身固定生成（如积分末尾的 `\,\mathrm{d}`），或作为普通字符输入，因此也不画方框。

### 键入

- **在结构内任意输入内容**：结构规定的位置（方框）里可以输入数字、字母、符号，也可以插入另一个结构；结构左右两侧的隐藏位置同样可以输入，内容会作为该结构的相邻部分。
- **在结构前后输入符号**：在结构左右两侧的隐藏位置输入单行算符，或点击相邻文本的边缘，即可把该结构与其他结构连接起来，例如 `∑…+∫…`。
- **四则运算等单行算符按字符处理**：`+`、`-`、`×`、`·`、`÷`、`=`、`≤` 等一律作为普通字符写入文本，它们**不是结构**，不会生成方框，不会把一段文字自动拆成多个结构，删除时也只删这个字符本身。例如输入 `x+2` 得到的就是一段文本 `x+2`；`-` 既可能是负号（`-x`）也可能是减号（`a-b`），都按字符处理，LaTeX 输出不受影响。
- **结构算符只能通过工具栏插入**，不会因为键入某个字符而出现；插入后光标自动落到第一个方框。删除时若删除方向上只剩一个结构算符，则把该算符和它内部的结构一并删除（详见「编辑与快捷键」）。
- 当前版本**没有**「键入单行算符时把当前结构拆成前后两个结构」的行为：分区的唯一依据是方框（结构算符的位置）和结构两侧的隐藏输入位置。

## 功能一览

- **可视化公式画布**：不显示 LaTeX 源代码，画布本身就是编辑器与实时预览。
- **点击方框输入**：模板中预留的黄色方框可以直接点击；结构两侧的隐藏输入位置不画方框，用方向键进入后也可直接输入。
- **点击算符前后定位**：在**大型运算符（求和、积分等）左右两侧的空白处**点击，光标会进入该算符前面/后面的隐藏输入位置，直接输入或插入结构即可在算符旁继续写公式。
- **点击文本边缘添加项（仅行内位置）**：在公式根行、求和项、被积函数、微分分子分母这些可以并排放结构的位置，点击一段文本的最左侧或最右侧边缘，会在这段文本前/后添加一个新的输入位置。积分/求和的上下限、分子分母、角标底数/上下标、矩阵单元格等方框里**不会**新增输入位置，填入内容后再插入结构也不会堆到方框外面（该位置已有内容时会提示先清空）。
- **拖动鼠标选中内容**：像常见文本编辑器一样，从**已填写的文本**上按住左键拖动即可选中一段内容；拖到某个算符（结构）上时，算符和它内部的所有结构会一起被选中。选中后直接输入可替换，`Backspace` / `Delete` 可删除，`←` / `→` 可把选择收拢到一端，单击空白处取消选择。空方框和隐藏空位不是内容，不能作为拖选起点，也不会被拖选删除。
- **删除方向只有算符时整体删除**：光标在结构左侧/右侧的空位，或恰好处在文本开头（按回格）/文本结尾（按 Delete）时，若删除方向上只剩一个结构（算符），则把算符和它内部的结构一并删除，而不是只删掉一个字符。回格只向左侧找、Delete 只向右侧找，另一侧永远不会被删到；行首空位按回格不回删右侧内容。
- **格位最前方回格：拆掉算符**：在任意大型算符的任意格位（分子分母、上下限、被积函数、角标底数/上下标、开方被开方数、矩阵单元格等）的**最前方**按 `Backspace`，会直接删除整个大型算符，并用当前格位的内容替换它。例如 `∑` 的求和项写了 `i^2`，在求和项开头按回格得到 `i^2`；分式分子写了 `a`，在分子开头按回格得到 `a`；空方框在格位最前方按回格则整个算符被删除。结构内部的固定字符（如微分的 `d`）属于算符本身，不会跟着内容留下。
- **自动适配的画布**：
  - 简单公式时画布保持较小高度，把空间留给输出区；
  - 公式变高时画布自动长高，直到窗口允许的上限；
  - 超过上限时自动缩小字号以适配。
- **常用结构模板**：
  - `∑ 求和`
  - `∫ 积分`
  - `d/dx 微分`
  - `a/b 分式`
  - `角标`（上角标（乘方） / 下角标 / 上下角标）
  - `√ 开方`（平方根 / n 次根）
  - `矩阵`（2×2、3×3、2×3、3×2）
  - `向量`（2×1、3×1 列向量；1×2、1×3 行向量）
- **单符号运算符面板**：
  - 直接按钮：`·`、`×`、`±`、`∓`、`≤`、`≥`、`≠`、`∞`、`∂`、`∇`
  - 「更多符号」按类别拆成六个下拉菜单：
    - `基本运算`：`+` `-` `*` `/` `=` `<` `>` `≠` `≤` `≥` `≈` `≡` `∝` `×` `÷` `·` `±` `∓` `≅` `≪` `≫` `∘`
    - `集合`：`∈` `∉` `∋` `⊂` `⊆` `⊄` `⊊` `⊃` `⊇` `∪` `∩` `∖` `∅` `ℕ` `ℤ` `ℚ` `ℝ` `ℂ`
    - `微积分`：`∫` `∬` `∭` `∮` `∂` `∇` `∞` `Δ` `′` `″`
    - `变量`：希腊字母（`希腊字母（小写）` / `希腊字母（大写）` 两个子菜单）
    - `标识`：`°` + `上标`（`⁰`…`⁹` `⁺` `⁻` `⁼` `ⁿ` `ⁱ`）/ `下标`（`₀`…`₉` `₊` `₋` `₌` `ₐ` `ₑ` `ₒ` `ₓ` `ₕ` `ₖ` `ₗ` `ₘ` `ₙ` `ₚ` `ₛ` `ₜ`）两个子菜单
    - `逻辑与箭头`：`∧` `∨` `¬` `∀` `∃` `∴` `∵` `→` `←` `↔` `⇒` `⇐` `⇔` `⊥` `∥`
- **模板嵌套**：先选中某个空方框，再点击模板按钮，可以把新模板插入到该位置。
- **结构两侧的隐藏输入位置**：每个结构左右自动存在一个可编辑位置，但不绘制方框；获得焦点时只显示光标。用 `←` / `→` 可从结构内部位置切到相邻空位，直接输入运算符、系数或另一个结构。
- **键盘导航**：`Tab` / `Shift+Tab` 在方框和已填写文本之间切换；`←` / `→` 在文本内移动光标，到达文本开头/结尾后自动切换到相邻输入位置；`Backspace` / `Delete` 删除字符。
- **实时 Markdown 输出**：
  - 左侧 Markdown 源码随公式即时更新；
  - 右侧公式渲染预览同步更新；
  - 只有所有必填方框都填写完整时，源码才生成、复制按钮才可用；结构两侧的隐藏位置可以留空。
- **编辑辅助**：撤销 / 重做 / 清空、Windows 剪贴板复制。

## 运行环境

本项目使用 conda 的 **transcript** 环境。当前环境已安装：

| 组件 | 版本/说明 |
| --- | --- |
| Python | 3.12.11 |
| Tkinter / Tk | Python 自带，Tk 8.6 |
| matplotlib-base | 3.10.9（使用 Agg 后端渲染输出预览） |
| Pillow | 11.1.0（用于预览图缩放与窗口图标） |

如需在新机器上重建环境：

```powershell
conda create -n transcript python=3.12.11 tk matplotlib-base=3.10.9 pillow=11.1.0 -y
conda activate transcript
```

> 这里安装 `matplotlib-base` 而不是 `matplotlib` 的完整 meta 包，是因为主要使用 Agg 后端，可以避免额外安装 PyQt 等 GUI 依赖。

## 启动程序

```powershell
conda activate transcript
python formula_editor.py
```

如果 conda 激活不方便，可以直接使用环境中的 Python：

```powershell
C:\Conda\envs\transcript\python.exe formula_editor.py
```

也可以使用包入口（与上面等价）：

```powershell
C:\Conda\envs\transcript\python.exe -m formula_editor_app
```

`formula_editor.py` 只是启动器，实际代码位于 `formula_editor_app/` 包中。

## 快速上手：求和公式

以输入下面的求和公式为例：

```
∑_{i=1}^{n} i²
```

1. 启动程序后，画布中央只有一个输入光标（初始根位置不显示方框），可以直接输入或插入模板。
2. 点击「∑ 求和」按钮，画布中会插入：
   - ∑ 符号；
   - 上方方框（求和上限）；
   - 下方方框（求和下限）；
   - 右侧方框（求和项）。
3. 用鼠标点击「求和下限」方框，输入 `i=1`。
4. 点击「求和上限」方框（或按 `Tab`），输入 `n`。
5. 点击右侧的「求和项」方框（或再按 `Tab`），输入 `i^2`。
6. Markdown 输出区会立即出现源码：

   ```markdown
   $$
   \sum_{i=1}^{n} i^2
   $$
   ```

   右侧同时显示渲染后的公式预览。

7. 点击底部「复制 Markdown」即可粘贴到 Typora、Obsidian、GitHub、VS Code 等支持 `$$` 数学公式的 Markdown 编辑器。

> 画布中的已填写文本仍然是普通字符，例如输入 `i^2` 时画布显示 `i^2`，右侧渲染预览会按 LaTeX 显示为 `i²`。最终排版效果以右侧预览为准。

## 新增运算符与大型结构

### 单符号运算符

运算符面板在工具栏的第二、三行：上一行是 10 个常用直接按钮，下一行是「更多符号」的六个分类菜单。点击即可插入到当前选中的方框或文本光标处。

| 按钮 | 含义 | 导出 LaTeX |
| --- | --- | --- |
| `·` | 点乘 / 内积 | `\cdot` |
| `×` | 叉乘 / 乘号 | `\times` |
| `±` | 正负 | `\pm` |
| `∓` | 负正 | `\mp` |
| `≤` `≥` `≠` | 关系符号 | `\leq` `\geq` `\neq` |
| `∞` | 无穷 | `\infty` |
| `∂` | 偏导符号 | `\partial` |
| `∇` | 梯度算子 | `\nabla` |

「更多符号」按钮收起了面板放不下的单行符号，按类别拆成六个下拉菜单：

| 分类 | 符号 | 导出 LaTeX |
| --- | --- | --- |
| 基本运算 | `+` `-` `*` `/` `=` `<` `>` `≠` `≤` `≥` `≈` `≡` `∝` `×` `÷` `·` `±` `∓` `≅` `≪` `≫` `∘` | `+`、`-`、`=` 等四则运算符号原样输出；`×` `÷` `·` `±` `∓` `≤` `≥` `≠` `≈` `≡` `∝` `≅` `≪` `≫` `∘` 转成 `\times` `\div` `\cdot` `\pm` `\mp` `\leq` `\geq` `\neq` `\approx` `\equiv` `\propto` `\cong` `\ll` `\gg` `\circ` |
| 集合 | `∈` `∉` `∋` `⊂` `⊆` `⊄` `⊊` `⊃` `⊇` `∪` `∩` `∖` `∅` `ℕ` `ℤ` `ℚ` `ℝ` `ℂ` | `\in` `\notin` `\ni` `\subset` `\subseteq` `\not\subset` `\subsetneq` `\supset` `\supseteq` `\cup` `\cap` `\setminus` `\emptyset` `\mathbb{N}` … |
| 微积分 | `∫` `∬` `∭` `∮` `∂` `∇` `∞` `Δ` `′` `″` | `\int` `\iint` `\iiint` `\oint` `\partial` `\nabla` `\infty` `\Delta` `^{\prime}` `^{\prime\prime}` |
| 变量 | 希腊字母：小写 `α`…`ω`，大写 `Γ` `Δ` `Θ` `Λ` `Ξ` `Π` `Σ` `Υ` `Φ` `Ψ` `Ω`（收在两级子菜单里） | `\alpha` … `\omega`、`\Gamma` … `\Omega` |
| 标识 | `°`；`上标` 子菜单：`⁰`…`⁹` `⁺` `⁻` `⁼` `ⁿ` `ⁱ`；`下标` 子菜单：`₀`…`₉` `₊` `₋` `₌` `ₐ` `ₑ` `ₒ` `ₓ` `ₕ` `ₖ` `ₗ` `ₘ` `ₙ` `ₚ` `ₛ` `ₜ` | `^{\circ}`；`²`→`^{2}`、`⁺`→`^{+}`、`ⁿ`→`^{n}`、`ₙ`→`_{n}`、`ₓ`→`_{x}` … |
| 逻辑与箭头 | `∧` `∨` `¬` `∀` `∃` `∴` `∵` `→` `←` `↔` `⇒` `⇐` `⇔` `⊥` `∥` | `\wedge` `\vee` `\neg` `\forall` `\exists` `\therefore` `\because` `\to` `\leftarrow` `\leftrightarrow` `\Rightarrow` `\Leftarrow` `\Leftrightarrow` `\perp` `\parallel` |

希腊字母在画布上用数学字体（Cambria，小写按变量斜体）显示，导出为 `\alpha` 这类命令；数集字母 `ℕ` `ℤ` `ℚ` `ℝ` `ℂ` 用符号字体正体显示，导出为 `\mathbb{N}` 等。

`标识` 里的是 Unicode 自带的上/下标字形：画布上直接显示成小号字符（例如 `x²`、`aₙ`），导出时会还原成标准的 `x^{2}`、`a_{n}`，所以粘贴到 Markdown 里仍然是规范 LaTeX。注意连续插入两个上标（如 `²` 后再插 `⁺`）会得到 `x^{2}^{+}`，这种写法 LaTeX 不接受，需要时请改用工具栏的「角标」结构。

冒烟测试会逐个检查面板里的每个符号：必须有 LaTeX 映射，并且能被 mathtext 正常渲染。

单符号作为普通文本插入，仍然可以点击后删除、移动光标或替换。

### 结构模板

| 按钮 | 插入结构 | 可编辑位置 |
| --- | --- | --- |
| ∑ 求和 | `\sum_{□}^{□} □` | 下限、上限、求和项 |
| ∫ 积分 | `\int_{□}^{□} □\,\mathrm{d}□` | 下限、上限、被积函数、积分变量 |
| d/dx 微分 | `\frac{\mathrm{d}□}{\mathrm{d}□}` | 分子变量、分母变量 |
| a/b 分式 | `\frac{□}{□}` | 分子、分母 |
| 角标 → 上角标（乘方） | `{□}^{□}` | 底数、上标 |
| 角标 → 下角标 | `{□}_{□}` | 底数、下标 |
| 角标 → 上下角标 | `{□}_{□}^{□}` | 底数、下标、上标 |
| √ 开方 | `\sqrt{□}` | 被开方数 |
| n 次根 | `\sqrt[□]{□}` | 被开方数、根指数 |
| 矩阵 | `\begin{pmatrix} … \end{pmatrix}` | 各单元格 |
| 向量 | `\begin{pmatrix} … \end{pmatrix}` | 各分量 |

「角标」是下拉菜单：上角标（即乘方，2 个空位：底数、上标）、下角标（2 个空位：底数、下标）、上下角标（3 个空位：底数、下标、上标）。角标和求和、积分一样是**算符结构**，而不是普通字符：插入后底数、下标、上标都是可点击的方框，画布上会把下标画在基线下方、上标画在基线上方。

「√ 开方」是下拉菜单，可选择平方根或 n 次根。

「矩阵」菜单提供 2×2、3×3、2×3、3×2 四种尺寸；「向量」菜单提供 2×1、3×1 列向量和 1×2、1×3 行向量。

### 示例：角标与开方

1. 点击「角标」→「上角标（乘方）」，出现底数和上标两个方框；
2. 在底数方框输入 `x`，按 `Tab` 在上标方框输入 `2`；
3. 得到源码：

   ```markdown
   $$
   {x}^{2}
   $$
   ```

4. 点击「角标」→「上下角标」，三个方框依次是底数、下标、上标；例如填写 `a`、`i`、`2`，源码为：

   ```markdown
   $$
   {a}_{i}^{2}
   $$
   ```

5. 点击「√ 开方」→「n 次根」，填写被开方数和根指数，例如 `x` 和 `3`，得到：

   ```markdown
   $$
   \sqrt[3]{x}
   $$
   ```

### 示例：矩阵与向量

1. 点击「矩阵」→「2 × 2 矩阵」，画布中出现 2×2 个方框；
2. 用鼠标点击单元格，或按 `Tab` 依次填写；
3. 例如填写 `a`、`b`、`c`、`d`，源码为：

   ```markdown
   $$
   \begin{pmatrix} a & b \\ c & d \end{pmatrix}
   $$
   ```

4. 点击「向量」→「3 × 1 列向量」，填写三个分量即可生成列向量。

矩阵单元格本身也是普通方框，可以在单元格里继续插入角标、分式、根号等结构。

> **矩阵预览说明**：matplotlib mathtext 不支持 `pmatrix` 环境，因此含矩阵/向量的公式，右侧实时预览会自动改用与画布相同的自绘布局；复制出的 Markdown 仍然是标准 `pmatrix`，可被 GitHub、Typora、Obsidian、VS Code 等支持 LaTeX 的 Markdown 渲染器正确显示。

### 在结构两侧输入内容

每个结构（求和、积分、微分/分式、角标、开方、矩阵等）的左右两侧会自动存在一个输入位置：

- 该位置**不绘制黄色方框**；获得焦点时只显示光标；
- 如果该侧已经有空方框或已填写文本，则直接复用已有位置，不重复生成；
- 使用 `←` / `→` 可以从结构内部位置切换到相邻的隐藏空位：
  - 在结构第一个内部位置按 `←` 进入左侧空位；
  - 在结构最后一个内部位置按 `→` 进入右侧空位；
  - 在空位中继续按反方向键可回到结构内部。

在右侧空位直接输入 `+`，再点击「∫ 积分」，即可得到：

```markdown
$$
\sum_{i=1}^{n} i^2+\int_{0}^{\infty} e^{-x^2}\,\mathrm{d}x
$$
```

结构内部用于填写上下限、分子分母、矩阵单元格等的空位仍然显示黄色方框；结构两侧的隐藏空位只是可选的扩展位置，保持空白也不会阻止复制。

### 点击文本边缘 / 算符两侧

除了用方向键进入隐藏空位，也可以直接点击来定位到算符前后的位置：

- **点击算符左侧/右侧的空白**：光标会进入该算符前面/后面的隐藏输入位置（例如点击求和左边的空白再输入 `a`，得到 `a\sum...`；点击右边空白再输入 `b`，得到 `\sum...b`）。算符内部的方框不会因此被改动。
- **点击文本边缘添加项（只对行内位置有效）**：

1. 在画布中输入一段文本，例如 `x`；
2. 将鼠标移到 `x` 的最左侧或最右侧，鼠标会变成手形；
3. 点击该边缘，文本前/后会出现一个新的输入光标位置；
4. 直接输入运算符、系数或文字，或者点击工具栏插入一个结构。

例如：在 `x` 右侧边缘点击，输入 `+`，再插入积分，即可得到 `x+\int...` 这样的组合。

> 边缘点击区域位于文本两端附近；文本中间仍然用于定位文本光标。如果该侧已经有隐藏空位或黄色方框，点击边缘会直接定位到已有位置，不会重复添加。
>
> 这个“添加位置”功能只在可以并排放结构的地方可用：公式根行、求和项、被积函数、微分分子分母。积分/求和的上下限、分子分母、角标底数/上下标、矩阵单元格等方框里的文本边缘不会变成手形，点击只定位光标；在已有内容的方框里再插入结构会被拒绝并提示先清空，避免结构“长”到方框外面。

## 画布大小与自动扩展

- 空白或简单公式时，画布保持较小高度，下方空间主要留给 Markdown 源码和预览。
- 插入求和、积分、矩阵或公式内容变高时，画布会自动变大。
- 画布高度上限随窗口高度调整；窗口越大，可扩展的高度越多。
- 超过上限时会自动降低字号适配。
- 删除内容后画布会自动缩回较小高度。

### 添加新功能时的修改位置

- **新增公式结构**：
  1. 在 `model.py` 增加节点类，并更新 `Element`、`child_slots()`、`iter_targets()`、`_iter_placeholders()`、`first_placeholder_in_node()`、`is_structure_item()`（`normalize_free_boundaries()` 通过 `child_slots()` 自动生效）；
  2. 在 `model.py` 的 `make_template()` 中登记；
  3. 在 `layout.py` 增加布局方法，并在 `_layout_item()` 中分派；
  4. 在 `model.py` 的 `serialize_item()` 中补充 LaTeX；
  5. 在 `ui.py` 加入按钮或菜单项（较长的类别可用 `_make_menu_button()` 做成下拉菜单）；
  6. 如需要，在 `smoke.py` 增加冒烟验证。
- **新增单个运算符符号**：在 `config.py` 的 `SYMBOL_LATEX` 里补上 `字形: LaTeX 命令`，再把字形放进 `SYMBOL_GROUPS` 相应的分类；长分类可以写成 `(子菜单名, 符号元组)` 收进级联子菜单。画布按 `SYMBOL_FONT_CHARS` 决定用符号字体还是数学字体，`PLAIN_OPERATOR_CHARS` 会随符号表自动更新（非字母符号按单字符处理，希腊字母这类字母仍按变量文本处理）。
- **新增交互/快捷键**：在 `app.py` 中处理，必要时在 `ui.py` 绑定控件。
- **新增预览渲染方式**：在 `preview.py` 中扩展。

## 实现说明与已知限制

- 画布是自定义公式编辑器，不是从 LaTeX 源码解析生成的只读预览；公式结构真正可点击、可编辑。
- 画布中的字体使用 Cambria（正文、希腊字母）和 Segoe UI Symbol（运算符符号、数集字母、上/下标字形）。方框内输入的是普通字符，画布不做完整的 LaTeX 排版；例如 `^2` 会保留为 `^2` 字符，最终排版请以右侧实时预览为准。
- 输出预览使用 **matplotlib mathtext**，支持常用数学结构，但不是完整 LaTeX 引擎。`pmatrix` 矩阵环境不被 mathtext 支持，因此矩阵公式使用自绘画布预览；`\begin{aligned}`、宏包、中文文本等其他不支持语法会在右侧显示错误，但源码仍可复制。
- 画布会随公式自动长高，但高度上限受窗口大小限制；超过上限后会自动缩小字号，而不是继续扩大窗口。
- 非结构型空位（结构左右两侧、初始空白根位置）不再绘制方框，只在获得焦点时显示光标；结构内部的上下限、分子分母、矩阵单元格等必填位置仍显示黄色方框。
- 四则运算等单行算符（`+`、`-`、`×`、`·`、`=` 等）一律按**字符**处理：不生成结构、不画方框、不自动拆分文本，删除时也只删字符本身。这是有意的设计，用来保留负号、`e^{-x^2}` 这类写法。
- `标识` 里的上/下标字形（`²`、`ₙ`、`°` 等）同样是普通字符：画布上显示为小号字形，导出时还原成 `x^{2}`、`a_{n}`、`30^{\circ}`。它们不会自己成组，所以连续插入两个上标（如 `²` 后再插 `⁺`）会得到 `x^{2}^{+}` 这种 LaTeX 不接受的写法；需要真正的上下标结构时请用工具栏的「角标」。
- 回格 / Delete 的「整体删除算符」规则只对**同一行里相邻的结构**生效：光标在结构两侧的隐藏空位，或文本开头（回格）/文本结尾（Delete）时，方向上的算符和内部结构一并删除；纯算符文本（整段都是 `+`、`-` 等字符）也只删字符本身。
- 在算符**任意格位（分子分母、上下限、被积函数、角标底数/上下标、被开方数、矩阵单元格等）的最前方**按 `Backspace`，是另一条更早触发的规则：删除整个算符，并用该格位的内容原地替换。例如 `∑` 求和项里的 `i^2` 会在回格后变成公式 `i^2`；空方框在最前方按回格则整个算符被删除。结构内部的固定字符（如微分的 `d`）属于算符本身，不随内容一起替换；文本中间按回格仍只删一个字符，不会触发拆分。
- 回格只向**左**找、Delete 只向**右**找：方向相反的一侧永远不会被删除。行首空位按回格不会删掉右侧的结构；`x+1` 开头按回格整体删除的是左侧的求和；文本内部按回格 / Delete 只删一个字符。光标在文本边界处按 `←` / `→` 会先进入同一行里紧挨着的相邻结构，不会跳过结构跑到别的方框里。
- 删除后若某一行整行都变成隐藏空位，会自动收缩为单个输入位置，不会留下一串看不见的空位；结构内部的必填方框不受影响。
- 鼠标拖动选择以画布上可见的**内容**为单位：已填写文本、整个结构。结构在拖动时以整体出现，因此拖到算符上会连同其内部内容一起选中；矩阵单元格按单元格矩形选中。选中后输入会替换选中内容，`Backspace` / `Delete` 会删除选中内容，`←` / `→` 会把选择收拢到一端。
- 空方框（结构规定的必填位置）和隐藏空位不是内容：它们不能作为拖选起点，也不会被拖选删除；删除选择时只会删掉文字和结构，结构被删时它的方框随结构一起消失。拖动过程中鼠标停在空方框上时，选择不会扩展到它所属的结构。
- 选中的方框和结构内部方框都改用选中底色绘制，不会被方框本身的颜色盖住；**光标停在被选中的方框里时也保持选中底色**，只用双线边框标示“正在编辑”。在已选中的内容里按下鼠标会先收拢选择，再开始新的拖选。
- 结构左右两侧的隐藏位置会自动生成；若该侧已有可编辑文本或方框则直接复用，不重复生成。用 `←` / `→` 可在结构内部位置和相邻隐藏位置之间切换。
- 矩阵和向量插入后尺寸固定，可先在菜单中选好尺寸；单元格内可以继续嵌套结构。
- Markdown 输出为 `$$ ... $$` 块级公式；如果目标平台只支持行内 `$...$`，可以后续增加输出格式切换。
