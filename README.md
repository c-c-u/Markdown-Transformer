# 公式编辑器 · Markdown 导出

一个基于 Python + Tkinter 的可视化公式编辑器。公式直接显示在画布中：点击公式里的黄色方框即可定位输入，使用工具栏插入求和、积分、微分模板；导出时生成 Markdown 块级公式，并在输出区同时展示 **Markdown 源码** 和 **渲染预览**。

## 功能一览

- **可视化公式画布**：不再有单独的 LaTeX 输入框，画布本身就是编辑器与实时预览。
- **点击方框输入**：公式模板中预留的黄色方框可以直接点击，随后用键盘输入数字、字母或符号。
- **常用模板按钮**：
  - `∑ 求和`
  - `∫ 积分`
  - `d/dx 微分`
- **模板嵌套**：先选中某个空方框，再点击模板按钮，可以把新模板插入到该位置。
- **键盘导航**：`Tab` / `Shift+Tab` 在方框和已填写文本之间切换；方向键在文本内移动光标；`Backspace` / `Delete` 删除字符。
- **实时渲染**：画布上的公式结构会随输入即时重排，方框、求和上下限、积分上下限、分式等都会自动布局。
- **Markdown 输出区**：
  - 左侧显示导出的 Markdown 源码，可直接复制；
  - 右侧显示公式的渲染预览，随公式自动更新；
  - 点击「导出 Markdown」后源码写入左侧文本框，「复制」按钮生效。
- **编辑辅助**：撤销 / 重做 / 清空。

## 运行环境

本项目使用 conda 的 **transcript** 环境。当前环境已安装：

| 组件 | 版本/说明 |
| --- | --- |
| Python | 3.12.11 |
| Tkinter / Tk | Python 自带，Tk 8.6 |
| matplotlib-base | 3.10.9（使用 Agg 后端渲染导出预览） |
| Pillow | 11.1.0（用于预览图缩放与窗口图标） |

如需在新机器上重建环境：

```powershell
conda create -n transcript python=3.12.11 tk matplotlib-base=3.10.9 pillow=11.1.0 -y
conda activate transcript
```

> 这里安装 `matplotlib-base` 而不是 `matplotlib` 的完整 meta 包，是因为只需要 Agg 后端，可以避免额外安装 PyQt 等 GUI 依赖。

## 启动程序

```powershell
conda activate transcript
python formula_editor.py
```

如果 conda 激活不方便，可以直接使用环境中的 Python：

```powershell
C:\Conda\envs\transcript\python.exe formula_editor.py
```

## 快速上手

以输入下面的求和公式为例：

```
∑_{i=1}^{n} i²
```

1. 启动程序后，画布中央有一个黄色空方框。
2. 点击「∑ 求和」按钮，画布中会插入：

   - ∑ 符号；
   - 上方方框（求和上限）；
   - 下方方框（求和下限）；
   - 右侧方框（求和项）。

3. 用鼠标点击「求和下限」方框，输入 `i=1`。
4. 点击「求和上限」方框（或按 `Tab`），输入 `n`。
5. 点击右侧的「求和项」方框（或再按 `Tab`），输入 `i^2`。
6. 右侧输出区会实时显示公式的渲染预览；点击「导出 Markdown」，左侧得到：

   ```markdown
   $$
   \sum_{i=1}^{n} i^2
   $$
   ```

7. 点击输出区右上角的「复制」即可粘贴到 Typora、Obsidian、GitHub、VS Code 等支持 `$$` 数学公式的 Markdown 编辑器。

> 画布中的已填写文本仍然是普通字符，例如输入 `i^2` 时画布显示 `i^2`，导出预览会按 LaTeX 显示为 `i²`。最终排版效果以右侧「导出预览」为准。

## 模板对照表

| 按钮 | 插入结构 | 方框/可编辑位置 |
| --- | --- | --- |
| ∑ 求和 | `\sum_{□}^{□} □` | 下限、上限、求和项 |
| ∫ 积分 | `\int_{□}^{□} □\,\mathrm{d}□` | 下限、上限、被积函数、积分变量 |
| d/dx 微分 | `\frac{\mathrm{d}□}{\mathrm{d}□}` | 分子中的变量、分母中的变量 |

- 空方框是黄色、虚线边框；被选中后变为蓝紫色实线边框。
- 已填写的文本仍然是可点击的：点击字符会把光标放到最近的字符位置，可以直接修改。
- `Tab` / `Shift+Tab` 会按填写顺序在所有方框和文本之间切换。

| 操作 | 方式 |

## 导出格式

导出为 Markdown 块级数学公式：

```markdown
$$
\sum_{i=1}^{n} i^2
$$
```

更复杂的例子：

```markdown
$$
\int_{0}^{\infty} e^{-x^2}\,\mathrm{d}x
$$
```

```markdown
$$
\frac{\mathrm{d}y}{\mathrm{d}x}
$$
```

导出的文本是一个完整的 Markdown 片段，可以直接粘贴到文档中，不需要再包一层代码围栏。

## 输出区说明

「Markdown 输出」区域分为两栏：

- **左侧 Markdown 源码**：点击导出按钮后写入，支持选择和复制。
- **右侧导出预览**：在所有方框都填写完成且公式可解析时，实时显示排版后的公式。

当还有未填写的方框时，右侧会显示剩余方框数量；预览渲染失败时会显示错误信息，此时仍可在确认后导出 Markdown，方便使用 mathtext 不支持但目标 Markdown 编辑器支持的语法。

## 项目结构

```
project/
├── formula_editor.py   # 主程序（公式树、画布布局、编辑交互、导出）
├── README.md           # 本说明文件
└── .git/               # 仓库元数据（如存在）
```

`formula_editor.py` 内部大致分为：

1. **公式树模型**：`Slot`、`TextRun`、`Placeholder`、`SumNode`、`IntegralNode`、`FractionNode`，用于表示可编辑公式结构。
2. **画布布局引擎**：计算每段文本、方框、求和/积分/分式的位置与尺寸，并生成点击热区。
3. **`FormulaEditorApp`**：
   - 构建 Tkinter/ttk 界面与交互式 Canvas；
   - 处理点击、键盘输入、Tab 跳转、撤销/重做；
   - 序列化为 LaTeX；
   - 用 matplotlib mathtext 渲染导出预览；
   - 导出、剪贴板复制和 Markdown 输出。
4. **`main()`**：DPI 感知、窗口入口和 `--smoke-test` 冒烟测试。

## 实现说明与已知限制

- 画布是自定义公式编辑器，而不是从 LaTeX 源码解析生成的只读预览；因此公式结构是真正可点击、可编辑的。
- 画布中的字体使用 Cambria（正文）和 Segoe UI Symbol（∑、∫）。方框内输入的是普通字符，画布不做完整的 LaTeX 排版；例如 `^2` 会保留为 `^2` 字符，最终排版请以右侧「导出预览」为准。
- 导出预览使用 **matplotlib mathtext**，支持常用数学结构，但不是完整 LaTeX 引擎。`\begin{aligned}`、宏包、中文文本等 mathtext 不支持的语法可能预览失败；此时程序会提示，但仍允许确认后导出。
- 画布会自动缩放公式以适配窗口大小，但不支持滚动查看超大公式；嵌套层级过多时字体可能缩小。
- 模板目前只提供求和、积分、微分。分式节点已经在内部实现（微分模板使用它），后续可以很方便地添加分式、根号、极限、乘积等模板。
- 导出的 Markdown 使用 `$$ ... $$` 块级公式；如果目标平台只支持行内 `$...$`，可以后续增加输出格式切换。

## 后续可以添加的公式符号

当前只实现了求和、积分、微分。可以按同样方式继续添加：

- 分式 `\frac{□}{□}`（`FractionNode` 已经可用）
- 根号 `\sqrt{□}` / `\sqrt[□]{□}`
- 极限 `\lim_{□ \to □} □`
- 乘积 `\prod_{□}^{□} □`
- 偏导 `\frac{\partial □}{\partial □}`
- 矩阵 / 分段函数 / 希腊字母面板
- 导出为行内公式、保存 `.md` 文件、更多画布交互

添加新模板时通常需要：

1. 在公式树中增加节点类型，或复用 `FractionNode` 等已有结构；
2. 在 `make_template()` 中登记模板；
3. 在工具栏加入按钮；
4. 在布局引擎中实现该结构的排版和点击热区（如需要）；
5. 在 `serialize_item()` 中补充 LaTeX 序列化。
